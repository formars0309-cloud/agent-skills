# 웹툰 업로드 공통 여백 규칙 — 2026-09-14

> 2026-09-27 전역 `~/.claude/CLAUDE.md`에서 옮겨 왔다(내용 그대로). 모든 작품의 납품 단계에서 이 파일을 읽는다.

- 모든 작품의 새 웹툰 업로드·수정 납품에 적용한다. 컷을 빈틈없이 연속으로 붙이지 않는다.
- 가로 690px 기준 컷 사이 총 여백은 기본 140px, 장면·시간 전환 240px, 프롤로그·회차 경계 320px로 시작한다. 다른 가로 폭에서는 비례 환산한다. 빠른 연속 동작은 80~100px까지 줄일 수 있으나 연출상 이유를 기록한다.
- 기존 이미지 안의 여백도 합산한다. 양쪽 패딩이나 플랫폼 간격과 중복해 두 배로 벌리지 않는다. 기존 충분한 여백을 다시 추가하지 않는다.
- 흰 바탕의 편집 여백으로 처리하며 작화·대사·표정은 재생성하지 않는다. 원본은 보존한다. 여백을 최종 납품 이미지의 캔버스에 포함하거나, 기존 이미지의 무손실 보존이 필요하면 별도 무문자 여백 JPG를 사이에 넣어 순서 목록으로 관리한다. 빈 여백 파일은 원고 컷수에 포함하지 않는다.
- HTML 미리보기의 CSS 간격만으로 끝내지 않는다. 실제 업로드 파일과 독자 화면에도 간격이 있어야 한다. 가로 690px JPG·개별 5MB 미만·회차 50MB 이하 및 플랫폼 파일수 제한을 확인한다.
- 390px 모바일 표시에서 기본 약79px, 장면 전환 약136px, 회차 경계 약181px가 된다. 컷 경계와 장면 전환을 확인하고 불필요한 긴 공백은 줄인다.
- 이 규칙은 앞으로 모든 작품에 적용하되, 요청하지 않은 다른 작품의 기존 공개 회차를 일괄 수정하거나 발행하지 않는다.
