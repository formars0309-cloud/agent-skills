# 제작 적용 예시

## 작품 정보를 주입하는 틀

공통 스킬에 프로젝트 절대 경로·정본 버전·캐릭터 설정을 박아 넣지 않는다. 현재 프로젝트에서 다음을 채운다.

```text
작품 / 컷 ID:
실제 캐릭터 참조 이미지 / 최신 수정 인계:
사건과 인물의 목표:
감정·강도 / 변형량:
눈썹 / 눈꺼풀 / 시선 대상 / 입:
목·어깨·손:
앞뒤 컷과 차이:
외형 고정 / 제외할 보조 효과:
한 컷의 구도 / 대사와 레터링 / 납품 규격:
```

## 예시 — 위엄을 지키려는 인물의 예상 밖 반응

기준 인물의 날카로운 눈매·성인 얼굴·검은 뿔과 머리·붉은 눈을 유지하는 가상의 시험이다. 특정 작품 전체 설정으로 쓰지 않는다.

**A, 뜻밖의 말을 들은 순간:** 놀람 3, 부분 과장. 눈썹 양쪽이 평소보다 올라가고 위 눈꺼풀이 열리지만 얼굴 골격은 유지. 동공은 말한 사람에게 고정. 입은 작게 벌어지며 입꼬리는 올라가지 않는다. 목이 약간 뒤로 물러나고 동작이 멎는다. 뺨의 붉은 기운·땀·속도선 없이 얼굴만으로 읽히는지 확인.

**B, 들뜬 마음을 감추고 태연한 척하는 순간:** 당황 은폐 2, 기준 유지. 한쪽 눈썹은 미세하게 올라가고 반대쪽은 기본 위치. 시선은 옆으로 피하고 입은 가로로 다물되 한쪽 끝에 작은 긴장. 턱을 당기고 어깨를 고정. A와 같은 구도·조명·참조를 사용해 표정 차이를 비교. 기본 미소가 되거나 분노로 읽히면 입꼬리·미간의 힘을 조정.

두 컷은 각각 독립 생성한다. 감정명을 그림 안에 써서 맞힌 것처럼 보이지 않도록 시험 이미지는 무대사로 만든다. 프롬프트·결과·시각 검수 기록은 작품 안에 보존하며 스킬에 원작 이미지나 프로젝트 캐릭터 이미지를 중복 보관하지 않는다.

## 수정 지시문 예시

```text
수정 대상은 첨부한 이번 컷이다. 눈과 입의 반응만 교정한다.
현재 웃는 입꼬리 때문에 '놀람'보다 '즐거움'이 먼저 읽힌다.
입꼬리를 중립으로 돌리고 입을 작게 벌린다. 위 눈꺼풀은 올라간 상태를 유지한다.
같은 인물의 얼굴 골격·연령·눈 색·머리·뿔·복장·구도·배경·대사와 레터링은 유지한다.
땀이나 홍조로 대신 설명하지 않는다. 한 컷만 출력한다.
```

## 검수 기록 형식

`컷 / 의도 / 실제 읽힌 감정 / 동일성 / 앞뒤 대비 / 축소 판독 / 판정 / 수정점`으로 기록한다. `미검수`, `수정 필요`, `이번 용도에서 사용 가능`을 구분한다. 사용자 승인과 자동 검수를 혼동하지 않는다.
