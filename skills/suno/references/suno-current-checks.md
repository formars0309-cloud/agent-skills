# Suno 공식 기능·조건 확인

확인일: 2026-09-08. 아래는 당시 공식 도움말을 요약한 탐색 기준이다. 모델·UI·플랜·권리는 바뀔 수 있으므로 실제 생성/상업용 납품 때 다시 읽는다. 계정 정보는 실제 화면에서 확인한다.

| 확인 대상 | 공식 출처와 당시 관측 |
|---|---|
| 효과음 | [Suno Sounds](https://help.suno.com/en/articles/10625537): Create의 Custom 드롭다운에서 Sounds. One Shot/Loop, BPM/Key 옵션, 생성 1회에 샘플 2개라고 안내. 베타 기능이며 실제 화면이 우선이다. |
| 다운로드 | [How do downloads work?](https://help.suno.com/en/articles/13876865): 2026-09-03 개정. Pro 월 20, Premier 월 60 다운로드 크레딧, Studio 워크플로는 해당 제한 제외라고 안내. 생성 크레딧과 다운로드 크레딧을 구분한다. |
| 상업 이용 | [유료 구독 권리](https://help.suno.com/en/articles/9601665): 2026-09-03 개정 안내는 구독 중 다운로드한 곡의 상업 이용과 게임 사용을 설명한다. 상업 이용 허용이 저작권 보호 보장을 뜻하지는 않는다. |
| 과거 자산 | [배포 안내](https://help.suno.com/en/articles/2410177): 검색 시 확인한 이전 안내에는 무료 플랜에서 생성한 곡의 소급 허용을 부정하는 문구가 있었다. 최신 안내와 기준 시점이 다를 수 있어 과거 무료 곡에 일괄 적용하지 않는다. 해당 곡·다운로드의 현재 조건과 [약관](https://suno.com/terms)을 대조한다. |
| 기타 메뉴·형식 | [공식 도움말](https://help.suno.com/): 다운로드 형식, 편집 도구 및 계정별 제공 기능은 실제 화면과 해당 문서로 확인한다. |

조건이 충돌하거나 Sounds 샘플에 대한 적용 범위를 확인할 수 없으면 상업 사용 가능이라고 단정하지 말고 미확인 항목을 남긴다. 확인한 날짜·출처·생성 및 다운로드 시점을 기록하되 계정 개인정보나 결제 화면을 저장소에 커밋하지 않는다.
