# 현자 비교와 전략 결정

작성일: 2026-09-18. 현자 ask_all.py로 Claude·Codex·Grok·Antigravity에 동일한 공식 사실과 질문을 제공했다. 상한은 CLI별 300초였다. 실행기는 정상 종료했고 응답은 Claude 52초, Codex 58초, Grok 121초, Antigravity 39초였다. **실질 전략 답변은 3개**다. Grok은 진행 문구만 반환해 비교·합의에서 제외했다. 모델의 응답은 의견이지 공식 정책 검증이 아니다.

## 차이와 채택

| 의견 | 판단 | 스킬에 반영한 내용 |
|---|---|---|
| Claude: 신규 블로그를 기본으로, 인용수를 유일한 선행 지표로 | 일부만 채택 | 좁은 주제와 근거 투명성은 채택. 신규가 우월하다는 증거가 없으므로 기존 채널 적합성부터 확인. 독자 효용·운영 비용도 본다. |
| Codex: 채널 적합성 → 미해결 질문 → 고유 가치 → 지표 분리 | 중심 전략으로 채택 | 기존/신규/독립 사이트 분기, 문서 기반 검증의 가치, 30일 실험과 시차를 반영한 평가. |
| Antigravity: 구조화 요약과 일관된 주제, 극단적인 건조체 | 일부만 채택 | 필요한 요약·표와 일관성은 채택. 요약 블록 의무·건조체·단일 주제 100%·비공개 점수 단정은 기각. |
| 3개 응답의 공통점: 직접 경험 조작·무검수 양산·허위 합격선 금지 | 공식 가이드와 대조 후 채택 | AI는 보조로 쓰되 실제 지식·검증과 역할 표시는 보존. 다수결만으로 채택하지 않음. |

## 기각·수정한 세부 주장

- '인용이 있는데 미선정이면 합격선 미달': 합격선과 가중치는 비공개이며 종합평가이므로 단정 불가.
- '신규의 첫 달은 0, 60일 뒤 첫 측정': 당월 인용 관측과 전전월 기반 선정 평가를 구분해야 함. 0을 미리 가정하지 않음.
- 'SEO는 의미 없다': 공식 가이드는 기존 검색에 잘 노출되는 좋은 글이 브리핑에 인용될 가능성이 높다고 설명함. 기계적 키워드 반복을 버리는 것과 검색 품질을 버리는 것은 다름.
- '3~4문장 요약이 없으면 반려', '건조한 사전식 글이 승률을 높임': 공식 가이드의 실제 경험·관점 강조와 충돌하며 인과 근거 없음.
- '방문=클릭', '모든 채널에서 검색 노출 통계를 확인 가능': 지표 이름·정의·접근 가능성을 실제 화면에서 확인해야 함.
- '12월에 끝나므로 이후 보상은 사라진다': 현재는 베타 일정만 확정. 종료/연장/변경 여부를 그때 공식 확인.
- '의료 콘텐츠는 행정 안내에만 국한', '모든 법률 글은 승인자 없으면 실패': 사용자의 실제 범위와 적용되는 검수 절차를 따름. 의료인 검수를 거친 의료 콘텐츠까지 배제하지 않음.

발행량 4편 안팎·질문 10개 안팎·30/60/90일 검토는 작업 여력에 맞춰 조정할 실험 시작안이다. 공식 추천량·합격 조건·통계적 유의성을 뜻하지 않는다.
