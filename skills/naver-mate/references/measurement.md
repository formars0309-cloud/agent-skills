# 관측과 실험 설계

이 문서는 네이버의 합격 공식이 아니라 운영 판단을 돕는 기록 방법이다. 발행 빈도·분량·내부 점수는 공식 선정 기준으로 표시하지 않는다.

## 최소 기록

| 항목 | 적을 내용 |
|---|---|
| 확인일·채널 | 한국시간 일시, 서비스, 공개 채널 URL |
| 정책 버전 | 공식 확인일·출처·실험 종료 전 정책 재확인일 |
| 인용수 | 지표 이름, 기간 시작/끝, 원 표시값, 정확값/반올림값, 관측 여부, 확인 화면 |
| 콘텐츠 | URL, 발행·실질 수정일, 해결 질문, 대상 주제, 새로 더한 검증·경험·도구 |
| 검색 관측 | 고정 질문, 조회일·환경, AI 브리핑 표시 여부, 내 출처 포함 여부 |
| 이용자 반응 | 관측 가능한 방문·검색 유입·질문 등; 정의와 제공 기간 |
| 결과 | 메이트 선정 월·주제·공식 알림/배지, 스페셜 여부, 수령 여부는 각각 별도 |
| 해석 | 변경한 요소, 계절/이슈/정책/채널 전체 변경 등 교란 요인, 다음 행동 |

계좌·신분정보·인증 값은 조사 파일에 넣지 않는다. 개인정보가 있는 화면은 필요한 집계값만 기록한다. 본인 확인 권한이 없는 타인의 비공개 통계를 얻으려 하지 않는다.

## 수치 해석

- 미관측, 접근 불가, 해당 없음, 실제 0을 구분한다. 보이지 않는 인용수는 0이 아니다.
- 누적·월간·당월 진행값을 섞지 않는다. 당월 10일 값은 전월 전체와 직접 비교하지 않는다. 월 일수와 데이터 지연도 적는다.
- 두 누적값의 차이는 동일 지표 정의·리셋 없음·정확값이 확인된 경우에만 해당 관측 구간의 순증으로 부른다. 공식 월간 수치와 동등하지 않다. '2.1만→2.2만' 같은 반올림 표시는 정확한 1,000회 증가로 계산하지 않는다.
- 채널 전체 인용수가 늘어도 특정 신작 덕분이라고 단정하지 않는다. 글별 수치가 제공되지 않으면 글별 인용수는 미확인이다.
- 인용수는 방문자·클릭·노출·선정 여부와 다르다. 한 번의 검색에서 출처 링크를 본 것은 그 질의·그 시점의 관측이다.
- 고정 질문 표본을 사용한다면 질문 목록과 분모를 함께 보존한다. 예: '질문 10개 중 브리핑 표시 6개, 그중 내 출처 1개'. 전체 시장 점유율이나 공식 채널 인용수로 부르지 않는다. 자동 반복 질의로 인용을 늘리려 하지 않는다.
- 정확한 0을 기준으로 증가율을 만들지 않는다. 소량·반올림 수치는 절대 변화와 관측 조건을 우선 보고한다.

## GEO 관측과 비교 실험

메이트 목적의 주 관측 대상은 네이버 AI 브리핑이다. AI탭·다른 AI 서비스도 관측할 수 있지만 서비스·화면·모드를 별도로 기록하며, 공식 인용 집계에 포함된다는 확인 없이 합산하지 않는다. 검색 결과 순위·AI 답변의 브랜드 언급·내 URL 출처 연결·공식 인용수·방문·선정을 각각 구분한다.

질문 10개 안팎의 작은 표본부터 시작할 수 있다. 질문 목록과 관측 주기를 먼저 정하고, 예컨대 주 1회 같은 조건에서 비교한다. 이는 작업량을 제한하는 예시이며 통계적 유의성이나 공식 권장 주기가 아니다. 잘 나온 질문만 남기거나 원하는 답변이 나올 때까지 반복하지 않는다. 새 질문은 기존 표본과 분리한다.

| 질문별 기록 | 내용 |
|---|---|
| 환경 | 질문 원문, 한국시간, 서비스·모드, 로그인 여부·기기, 새 대화/후속 질문 여부와 필요한 맥락 |
| 표시 상태 | AI 답변 표시 / 미표시 / 확인 실패. 실패를 미표시나 인용 0으로 바꾸지 않음 |
| 출처 | 내 URL 연결 여부·정확한 URL, 다른 출처 링크, 브랜드 언급만인지 구분 |
| 인용 정확성 | 인용과 연결된 주장·원문 위치, 수치·대상·조건·예외의 일치 / 왜곡 / 판단 불가 |
| 증거 | 확인 가능한 검색 주소·공개 공유 주소 또는 개인정보를 가린 화면 기록. 주소만으로 동일 답변 재현을 보장하지 않음 |

분모는 세 단계로 보존한다. 예를 들어 질문 10개를 계획했지만 2개 확인에 실패했다면, 성공 관측은 8개다. 그중 브리핑 5개, 내 URL 출처 2개이면 **확인 실패 2/10, 브리핑 표시 5/8, 표시 답변 중 내 출처 2/5**로 기록한다. 성공 관측 전체 기준 2/8을 추가할 수 있지만 분모를 붙인다. 같은 답변에 내 링크가 여러 번 나와도 이 표본의 ‘출처 포함 답변’은 1건으로 센다. 네이버의 공식 인용수 집계 방식과 동일하다고 주장하지 않는다. 분모가 0이면 비율은 해당 없음이다.

인용 정확성도 개별 주장 검수가 불가능하면 미확인이다. 출처 링크 확인만으로 정확성 통과를 주지 않는다. 의료·비용·자격 정보에서 핵심 조건이 빠진 인용은 노출 성공과 별도로 오류로 남긴다.

변경 전후 비교는 다음처럼 작게 설계한다.

1. 공개 URL·원고 버전/해시·실질 수정일과 기준선 관측을 남긴다. 초안이면 실험 준비 단계로 표시한다.
2. 우선 가설 하나를 정한다. 예: ‘답변 문단에 적용 조건과 근거를 가까이 두면 잘못 요약되는 경우가 줄어드는가’. 제목·주제·형식·근거를 한꺼번에 바꾸면 각각의 효과를 분리할 수 없다고 기록한다.
3. 가능하면 주제·글의 연령·기존 유입이 비슷한 미수정 글도 관측한다. 필수 대조군이나 무작위 실험으로 부르지 않는다. 비교 때문에 사실 오류 수정을 미루지 않는다.
4. 같은 표본과 비교 가능한 기간을 사용한다. 수정 직후 미반영, 계절·이슈·모델 변경, 다른 글 발행 등 교란 요인을 기록한다.
5. 30일에는 관측과 제작 비용을 검토하고, 메이트 선정은 아래 집계 시차를 적용한다. 변화가 작거나 표본이 부족하면 ‘효과 불명’으로 두고 보장·인과 주장 없이 유지/수정/중단을 결정한다.

## 선정의 시차

현재 규칙에서 일반 선정 월 M은 M−2월 인용을 중심으로 본다. 9월의 활동을 9월 미선정으로 평가하지 않는다. 9월 활동은 규칙이 유지될 경우 11월 일반 선정과 연관해 살펴볼 수 있다. 스페셜은 메이트로 선정된 M월의 활동을 평가한다. 공개 누적 랭킹을 합격선으로 사용하지 않는다.

2026-09-18 시작 사례: 9월 기준선 수집 → 10월 콘텐츠·관측 비교 → 11월에 9월 활동과 선정 여부 확인 → 12월 베타 종료 및 2027년 운영 공지 재확인. 2027년 운영·지원금을 현재 확정하지 않는다. 60~90일은 검토 시점이며 그 안에 선정이 보장되는 기간이 아니다.

## 판단 순서

1. 인용이 미확인이라면 접근·표시·집계기간 문제부터 확인한다. 실패로 평가하지 않는다.
2. 검색 유입과 표본 노출도 없다면 주제 수요, 문서 검색 가능 여부, 질문 적합성을 먼저 점검한다. 링크 한두 번 안 보인 것만으로 미색인을 확정하지 않는다.
3. 검색 반응은 있으나 인용이 관측되지 않으면 고유 근거와 답의 구조를 검토한다. 구조만 고치면 인용된다고 약속하지 않는다.
4. 인용 증가가 있으나 메이트 미선정이면 시차·서비스 조건·정책과 종합평가를 확인한다. 공개되지 않은 합격선을 만들지 않는다.
5. 실질 개선과 충분한 관측기간 후에도 독자 반응이 없으면 질문 범위를 줄이거나 소재를 바꾸는 작은 실험을 제안한다. 즉시 새 채널 생성·전면 주제 변경·대량 삭제를 실행하지 않는다.
