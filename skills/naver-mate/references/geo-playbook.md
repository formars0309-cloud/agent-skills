# 네이버 메이트에 GEO 적용하기

근거 확인일: 2026-09-18. 아래의 구체적 편집·실험 방법은 운영 가설이며, 네이버가 공개한 합격 공식이 아니다. 전략 설계 또는 GEO 관점의 원고 검수 때 읽는다.

## 근거와 적용 범위

| 근거 | 확인한 내용 | 적용의 한계 |
|---|---|---|
| [네이버 선정 기준](https://help.naver.com/service/30056/contents/25203?lang=ko&osType=COMMONOS) | 전전월 AI 브리핑 인용과 전문성·활동성·신뢰도·이용자 반응·검색 활용도 등을 종합평가 | 인용 증가만으로 선정·지원금 수령을 예측할 수 없음 |
| [네이버 콘텐츠 가이드](https://blog.naver.com/naver_search/224296857688), [실전편](https://blog.naver.com/naver_search/224305800678) | 경험과 지식, 투명한 출처, 읽기 쉬운 구성, 유효한 정보. 독자 상황·절차·대안·결과를 구체화 | 질문형 소제목·표·답변 문단의 고정 개수나 길이는 공식 조건이 아님 |
| [GEO 원논문, KDD 2024](https://arxiv.org/html/2311.09735v3) | 출처·인용문·통계 등의 편집으로 생성 답변 내 가시성이 개선된 실험. 방법별 효과는 분야마다 달랐음 | 주 실험은 검색 상위 5개 문서와 GPT-3.5 기반 환경이며 Perplexity 실험도 포함. 네이버·한국어 채널·메이트 선정을 검증한 결과가 아님 |
| [Google의 AI 검색 지침](https://developers.google.com/search/docs/appearance/ai-features) | 기존 SEO 원칙이 유효하며 AI 노출용 특수 파일이나 전용 스키마가 필수는 아님 | Google AI Overviews·AI Mode에 대한 안내. 네이버나 모든 AI 엔진의 기술 조건으로 일반화하지 않음 |

논문의 ‘최대 40%’는 해당 실험의 가시성 개선 결과다. 네이버 인용수 40% 증가, 평균 효과, 방문 증가, 선정 확률로 바꾸어 쓰지 않는다. 연구의 콘텐츠 변형 방법을 실제 발행 지침으로 그대로 복제하지 않는다. 검증되지 않은 통계·인용을 추가해 실험 효과를 흉내 내지 않는다.

## 적용할 편집 전략

**질문을 연결한다.** 한 글이 답할 중심 질문을 정하고, 독자가 다음으로 판단할 비교·방법·예외 질문을 붙인다. 하나의 답으로 해결되는 질문은 같은 글에 둔다. 다른 독자 상황과 독립적인 근거가 필요한 경우에만 별도 글로 나눈다. 관련 글 링크는 다음 판단을 도울 때 사용한다. 질문 묶음이나 내부 링크의 숫자를 권위 점수로 취급하지 않는다.

**이 글을 인용해야 할 이유를 만든다.** 직접 확인한 과정, 재현 가능한 계산, 원문 간 조건 비교, 적용 범위를 밝힌 점검표 등 고유한 도움을 하나 정한다. 브랜드 이름 반복이나 공식 문서의 재요약을 고유 근거로 계산하지 않는다. 저자·채널·전문 분야의 표기는 실제 이력과 맞추며, 메이트 배지를 전문 자격이나 의료 검토 증명으로 쓰지 않는다.

**문단만 읽어도 오해가 없게 한다.** 핵심 답 가까이에 대상·조건·예외·근거를 배치한다. 지시어만으로 대상을 설명하거나, 표 제목과 각주를 떼면 수치의 의미가 바뀌는 구성을 고친다. 무조건 짧게 줄이지 말고 의미를 유지하는 길이를 택한다. 이는 사람과 AI의 해석 오류를 줄이려는 편집 가설이며 인용 보장 기법이 아니다.

예시: “온라인으로 신청하면 됩니다. 예외는 아래를 보세요.”를 “이 제도의 온라인 신청은 [대상 조건]에 해당할 때 가능합니다. [예외 조건]이면 [다른 절차]가 필요합니다. [공식 원문·기준일]”로 바꾸는 식이다. 대괄호는 설명용 자리표시자이며 실제 검증한 정보가 없으면 발행문에 채우지 않는다.

**주장과 근거를 연결한다.** 중요한 수치·조건 바로 옆에서 출처를 찾을 수 있게 한다. 논문이나 통계는 대상·기간·분모·단위와 한계를 유지하고, 인용문은 원문과 일치하는지 확인한다. 확인 날짜와 자료의 실제 기준일을 구분한다. 문장 다듬기 때문에 “가능하다”가 “보장된다”로 바뀌면 수정한다.

**이미지와 본문을 함께 확인한다.** 핵심 비교나 절차가 이미지에만 있으면 본문에도 쓴다. 본문·표·카드의 숫자와 예외가 일치해야 한다. 이용 가능한 mobile-blog-readability 스킬과 프로젝트의 가독성 규칙을 적용하되 의미 보존을 우선한다. 정보가 바뀌면 실질 수정하고 날짜만 갱신하지 않는다.

## 원고 검수와 공개 후 검수

원고는 각 항목을 `충족 / 수정 필요 / 미확인 / 해당 없음`으로 기록하고 근거 문장·위치와 수정안을 붙인다. 합산 점수를 메이트 선정 점수로 환산하지 않는다.

- 독자의 중심 질문과 답이 일치하는가?
- 기존 답에 없는 검증 가능한 도움과 작성자의 실제 역할이 드러나는가?
- 핵심 문단이나 표를 따로 보아도 대상·조건·수치·예외가 유지되는가?
- 중요한 주장을 출처의 정확한 내용과 연결할 수 있는가?
- 이미지·본문·관련 글의 사실이 일치하는가?

공개 후에는 [측정 규칙](measurement.md)의 고정 질문 표본에서 출처 연결과 답변 내용을 확인한다. 브랜드 언급만 있는 경우, 다른 사이트가 대신 인용된 경우, 내 글의 URL이 연결된 경우를 구분한다. 링크만 있다고 내 주장이 정확히 전달됐다고 판단하지 않는다.

잘못 인용됐다면 원문부터 대조한다. 원문의 모호함은 고치고, AI 답변만 틀렸다면 관측 시점·질문·오류를 기록해 제공되는 신고·피드백 수단을 검토한다. AI가 잘못 인용했다는 이유로 올바른 원문을 틀린 주장에 맞춰 바꾸지 않는다. 의료 글은 인용을 잘 받기 위해 제한 조건이나 검토 상태를 숨기지 않는다.

## 채택하지 않는 전략

- 근거 없는 단정·전문용어·통계·인용문을 늘려 권위 있어 보이게 만들기.
- 모든 글의 FAQ·표·요약 개수, 글자 수, 키워드 밀도를 고정하기.
- 유사 질문별 복제 글, 허위 후기, 유료 언급·링크·품앗이로 신뢰를 꾸미기.
- 문서에 AI 대상 지시문이나 숨김 문구를 넣어 답변·인용을 유도하기.
- llms.txt나 구조화 데이터 설치를 네이버 메이트의 필수 조건·인용 보장으로 판매하기.
- 네이버에서 검색되지 않는 문제를 글의 문체만 바꾸어 해결하려 하거나, Google·ChatGPT에서의 노출을 네이버 성과로 합산하기.
