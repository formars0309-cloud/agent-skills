# 공식 기준과 재확인 출처

마지막 확인: 2026-09-18. 정책의 영구 정본이 아니라 날짜가 있는 참고 기록이다. 실행 시작 시 현재 공식 안내와 대상 서비스 공지를 대조한다. 충돌하면 더 최신이고 해당 서비스에 구체적인 안내를 따른다. 접속 실패는 정책 유지의 증거가 아니다.

## 정책

- 2026년 6~12월 베타. 대상은 블로그·카페·지식iN·프리미엄콘텐츠. 독립 사이트는 공지된 대상이 아니다. 클립·AI탭 반영은 발표 당시 계획이므로 실제 시행 공지를 확인하기 전 적용 중이라고 쓰지 않는다.
- 별도 선정 신청 없이 매월 자동 검토. 전전월 AI 브리핑 인용수와 주제 전문성·활동성·신뢰도·이용자 반응·검색 활용도를 종합 평가한다. 비공개 가중치와 합격 인용수는 추정하여 규칙으로 만들지 않는다.
- 선정 후 한 달 유지, 연속 선정 가능. 카페는 게시판을 평가해 그 카페를 지원한다.
- 블로그 선정 주제는 등록한 주제명보다 최근 작성한 콘텐츠가 기준. 프로필 설정만 바꿔 주제 선정이 달라진다고 가정하지 않는다.
- 기본 지원금은 선정 월 30만 원. 스페셜은 선정 월의 활동과 인용 등을 평가하며, 매월 100명에게 300만 원·10명에게 1,000만 원을 추가 지원하는 안내다. 기준 충족자가 없으면 미선정 가능. 선정과 지원금 수령 절차는 별개이며 지급 제외 조건도 확인한다.
- 공식 배지·주제별 소개는 선정 기간과 관련 주제에 적용된다. 상위 노출 보장, 인용당 과금, 의학적 검증 인증으로 해석하지 않는다.

## 인용과 콘텐츠

공개 프로필 인용수는 2026년 1월부터 누적값이다. 일반 선정의 전전월 값, 스페셜의 선정 월 값과 구분한다. 비선정자는 로그인한 본인만 인용수를 확인할 수 있다. 공식 화면에 누적·당월·전전월 값이 있으면 기간별로 기록하고, 보이지 않는 항목은 미확인으로 둔다.

공식 작성 가이드의 요지는 직접 경험·전문 지식, 주제 일관성, 출처와 이해관계의 투명한 표시, 읽기 쉬운 구조, 정보의 유효성 유지다. 중요한 이미지 정보는 텍스트로도 전달한다. 안정적인 정보는 억지로 최신 날짜로 바꾸기보다 내용의 깊이를 개선한다.

AI 도구 사용 자체에 무조건 불이익이 있다는 안내는 아니다. 작성자의 실제 지식·검토·편집이 필요하며 기계적 생성·요약의 무분별한 발행, 무관한 키워드·미디어, 홍보성 외부 링크 남용은 피하라는 안내다. 광고 글도 대가 공개와 실질적 정보가 있으면 일률 배제된다고 단정하지 않는다. 출처 링크까지 없애라는 의미가 아니다.

## 조사에서 확인한 측정 함정

2026-09-18 관련 검색 조사에서 블로그 검색 API는 정렬에 따라 total과 도메인 구성이 달랐다. 발달지연의 sim total은 432,679, date total은 38,226이었고 sim 표본에는 외부 블로그와 무관 문서도 포함됐다. 이 사건은 모든 API 호출이 틀리다는 증거가 아니라 자동 포화도 등급을 실제 화면과 대조해야 한다는 사례다. API total을 네이버 정보글 수·AI 인용수·합격 가능성으로 변환하지 않는다.
